# Screenshots

Original screenshots used as E-E-A-T "Experience" signals on info pages. Each `<figure>` on an info page references one of these files. If a file is missing, the figure auto-hides via `onerror` so the page still renders cleanly.

Suggested format: WebP, 1200px wide max, under 200KB. PNG also fine.
